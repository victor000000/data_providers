## Operational limits

No production maintenance/download cycle, broker order, cloud upload or scheduled
automation was started for this extraction. Vendor connectivity and current
subscription entitlements were not exercised. Live databases and credentials
were subsequently relocated into this project at the user's explicit request;
see the runtime cutover evidence below.

The HTTP interface is a bounded read service. Use immutable exports for consumers
that need stable datasets while DuckDB files are being written. The supervisor's
writer lock coordinates supervised runs; individual legacy jobs still rely on
DuckDB file locks and their own vendor-specific error reporting.

KQ/YC layouts without a normalized loader are preserved as lossless source
receipts; automatic cross-export execution reconciliation is not implemented.
CN true option-minute data and QuantConnect cloud custom-data hosting retain the
pre-existing limitations described in the README.
